# Buskirooms · modpack

Modpack del servidor de Minecraft de los Buskirooms (NeoForge 26.1.2).

## Cómo jugar

1. Instala [Prism Launcher](https://prismlauncher.org) e inicia sesión con tu cuenta de Minecraft.
2. En Prism: **Añadir instancia → Importar** y pega esta URL:
   ```
   https://github.com/ItsBuski/buskirooms-pack/raw/main/instancia/Buskirooms.zip
   ```
3. Pulsa **Jugar**. La primera vez se descargan los mods (sale una ventanita de progreso) y entras directamente al servidor.

Cada vez que pulses Jugar, la instancia comprueba este repositorio y añade o quita mods para que coincidan con el servidor. No hace falta tocar nada a mano.

El servidor solo está disponible cuando está encendido: mira el canal `#minecraft-server` del Discord.

---
Formato [packwiz](https://packwiz.infra.link). Se gestiona con `pack.py` desde el PC del servidor.
